# Designing for Indian Context

A guidebook for a five-tool design-research toolkit: AOIIV, STURFRY,
I SPY, Language and Material. The work happens offline; this site
explains each tool and how they connect.

Static site — no build step. Open `index.html`, or visit the live page.

| | |
|---|---|
| `index.html` | shell and markup |
| `tokens.css` | design tokens: colour, type, layout, spacing |
| `app.css`    | components |
| `content.js` | all page content |
| `app.js`     | renderers, router and diagrams |
| `assets/`    | illustrations and diagrams |
